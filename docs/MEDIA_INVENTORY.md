## Replacing a placeholder

1. Create an authentic Hue screenshot/diagram or a GIF demonstrating the specified interaction. Keep relevant Unreal UI labels and source states legible.
2. Save the final asset under `docs/assets/media/` using its filename in the table.
3. Update that figure's `<img src>` in its Markdown page to the correct **relative** asset path. The page uses a stable `data-media-id`; keep its ID and intended kind consistent with [the registry](assets/media-slots.json).
4. Keep the reader caption accurate and refine its alt text. Remove the separate capture instruction only when the intended final visual has been verified.
5. Test the image/GIF in the website on both desktop and mobile. Images must remain inside the article column, with no forced distortion.

The real Hue hero should not be replaced by a neutral placeholder.
