# Hue Roadmap

**Current documented release: Hue v1.0.0 (Released).** The available repository supports a shipped 1.0 baseline. No official later milestones, delivery dates or approved next-version feature list were supplied.

## v1.0.0 — Persistent Blueprint Styling (Released)

Hue introduces four independent node visual channels, Instance/Category/Global styling, nested Category inheritance, rename migration, batch editing, context menus and a dedicated Blueprint panel. Native-compatible presentation paths retain Unreal's editable controls. The plugin is editor-only and does not alter packaged-game behavior.

## Future development — Not yet committed

Additional node-presentation compatibility, usability refinements, new styling workflows and documentation improvements may be considered as needs emerge. **These are possible areas of investigation, not confirmed planned features or a v2.0 commitment.**

When an actual product plan is approved, document each proposed milestone with **Planned**, **In Development**, or **Released** status and preserve historical release summaries. Do not put unimplemented ideas into the current-feature manual.

## Future quality gates

- Validate existing supported node families in the target Unreal version.
- Preserve native controls and the no-gameplay-impact boundary.
- Test category renames, nested overrides, one-transaction batch Undo, global config persistence and unsupported nodes.
- Document every shipped feature with paired Design and Technical pages, real UI imagery and verified edge cases.
